SkyPulse APK Project

این پروژه یک اپ اندرویدی WebView برای داشبورد SkyPulse است.
آدرس متصل‌شده:
https://weather-dashboard-production-cf76.up.railway.app

ساخت APK با Android Studio:
1) ZIP را Extract کن.
2) پوشه SkyPulseAPK را در Android Studio باز کن.
3) Sync Project with Gradle Files را بزن.
4) Build > Build APK(s) را انتخاب کن.
5) فایل APK در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

برای نسخه انتشار: Build > Generate Signed Bundle / APK.
